프로젝트의 모든 html 파일을 점검하고 결과를 표로 보고할 것.

## 점검 항목

1. **제목**
   - `<title>` 태그가 존재하고 비어 있지 않은가
   - `<h1>`이 페이지당 정확히 1개인가

2. **깨진 링크**
   - 모든 `<a href>`의 로컬 경로가 실제 파일로 존재하는가
   - 모든 `<img src>`, `<link href>`, `<script src>`의 로컬 경로가 실제 파일로 존재하는가
   - 모든 `<img>`에 `alt` 속성이 있는가
   - 페이지 내 앵커(`#id`)가 해당 페이지에 실제로 존재하는가

3. **콘솔 에러**
   - 각 페이지를 브라우저로 열어 콘솔 에러/경고를 수집
   - 리소스 404, JS 런타임 에러를 모두 기록

## 보고 형식

아래 표로 정리해서 보고할 것.

| 파일 | 제목 | 링크 | 콘솔 | 상태 |
|---|---|---|---|---|
| index.html | ✅ | ✅ | ✅ | 통과 |
| test.html | ✅ | ❌ | ✅ | 수정필요 |

- 상태는 **통과** 또는 **수정필요** 둘 중 하나.
- 표 아래에 **수정필요** 항목만 파일별로 구체적인 문제와 수정 방안을 적을 것.
- 점검만 하고 코드는 수정하지 않는다. 수정은 사용자가 지시할 때만 진행.
